## Common Design Tokens

Use the core theme docs as the source of truth for shared design-system variables:

- [Theme Colors](../../jb-core/theme/stories/colors.mdx) explains the general color palette variables, default colors, customization approaches, and color generation helpers.
- [Theme Sizes](../../jb-core/theme/stories/sizes.mdx) explains shared size and radius variables.
- [Theme Custom Galleries](https://javadbat.github.io/design-system/?path=/docs/theme-custom-material--docs) gathers the shared custom style recipes across components.

Loading recipes should use those common tokens where possible, then map them into `--jb-loading-color`, `--jb-loading-width`, and `--jb-loading-height` where the spinner needs component-specific values.

## Styling Model

Use four layers when styling loading examples:

- Common design tokens are documented in [Theme Colors](../../jb-core/theme/stories/colors.mdx) and [Theme Sizes](../../jb-core/theme/stories/sizes.mdx).
- Reusable example theme packs live in [`docs/styles`](https://github.com/javadbat/design-system/tree/main/docs/styles) and can be shared across components.
- Component recipe files live in [`modules/jb-loading/stories/styles`](https://github.com/javadbat/design-system/tree/main/modules/jb-loading/stories/styles).
- Public component variables use `--jb-loading-*` on `jb-loading`.

Each example uses one shared example theme pack from [`docs/styles`](https://github.com/javadbat/design-system/tree/main/docs/styles) and one loading-specific recipe from [`modules/jb-loading/stories/styles`](https://github.com/javadbat/design-system/tree/main/modules/jb-loading/stories/styles). The style story applies both classes directly to `JBLoading`.

## Recommended Customization Path

1. Use `--jb-loading-width` and `--jb-loading-height` to set the spinner footprint.
2. Use `--jb-loading-color` for the spinner stroke color.
3. Use common theme variables from [Theme Colors](../../jb-core/theme/stories/colors.mdx) and [Theme Sizes](../../jb-core/theme/stories/sizes.mdx) when the style should align with the design system.
4. Put reusable theme-pack values in [`docs/styles`](https://github.com/javadbat/design-system/tree/main/docs/styles) only when they should be shared by multiple component demos.
5. Add a new loading variable or official part only when a needed internal surface cannot be customized with current public variables.

## Parts And States

`JBLoading` does not currently expose CSS parts or custom states. Style the host with public variables.

## Starter Recipe

Use this minimal recipe when a product only needs brand alignment.

```css
jb-loading.brand-loading {
  --jb-loading-width: 2rem;
  --jb-loading-height: 2rem;
  --jb-loading-color: #2563eb;
}
```

## Theme File Pattern

Use [Theme Colors](../../jb-core/theme/stories/colors.mdx) and [Theme Sizes](../../jb-core/theme/stories/sizes.mdx) as the common design-token guides. Theme-pack files should keep reusable demo variables in [`docs/styles`](https://github.com/javadbat/design-system/tree/main/docs/styles), then each component should keep its own style CSS in its story [`styles`](https://github.com/javadbat/design-system/tree/main/modules/jb-loading/stories/styles) folder.

```css
/* https://github.com/javadbat/design-system/blob/main/docs/styles/carbon.css */
.theme-name-style {
  /* shared design-system variables */
}

/* https://github.com/javadbat/design-system/blob/main/modules/jb-loading/stories/styles/style-carbon.css */
jb-loading.theme-name-loading {
  /* loading host variables */
}
```

This keeps common theme tokens reusable while making the `JBLoading` styling API visible in one page.
